JC's Birthday — 3D Cake Sample V3 RESPONSIVE

This version focuses on actual mobile/tablet usability.

Responsive behavior:
- Desktop: full 3-column creator
- Tablet: 2-column layout with settings below
- Mobile: cake-first layout with no squeezed sidebars
- Sticky top category tabs on the 3D stage
- Sticky bottom action bar
- Real bottom-sheet editor for Cake / Frosting / Decor / Candles / Scene
- Large touch targets
- Scroll/swipe-friendly controls
- Bottom sheet can be closed so the cake stays visible
- Preview opens as a mobile bottom sheet
- Drag to rotate and pinch to zoom remain fully available

Mobile bottom-sheet controls include:
- Cake shape
- 1/2/3 tiers
- 6 flavors
- Cake stand colors
- Frosting colors
- Custom frosting color/HEX
- 6 frosting finishes
- 12 decoration families
- Candle count
- 3 candle styles
- Number candle
- Topper message
- Background colors
- Studio / Party / Night scenes
- Auto rotate
- Confetti
- Soft light

This is still a standalone sample and does not replace the main JC's Birthday app.
