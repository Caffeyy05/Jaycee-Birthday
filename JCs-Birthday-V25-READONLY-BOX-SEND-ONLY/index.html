Quick help

Using the gift editor

Each gift has its own controls. On phones, use the bottom toolbar or the tabs near the top of the creator. Your gift isn't sent until you choose the final Send button inside the creator.

One-time owner setup

Connect the shared Birthday Box

The app is safely saving gifts on this device, but Supabase still needs the Birthday Box table before gifts can sync between different devices.

  1. Open your Supabase project.
  2. Go to SQL Editor → New query.
  3. Open SUPABASE-SETUP.sql from this app package, copy everything, paste it into Supabase, and press Run.
  4. Come back here and press Check again.
The SQL is idempotent, so it is safe to run again if you previously attempted the setup.
