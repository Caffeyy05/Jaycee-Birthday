

V18 — CLEAN CHAT
----------------
- Removed visible "joined" chat notices.
- Removed visible "left" chat notices.
- Online count still updates.
- Live chat, typing indicator, safe-chat filter, and shared Birthday Box remain.


V19 — CHAT REMOVED
------------------
The public chat feature has been removed completely.

Still enabled:
- Supabase online-user counter
- Shared Supabase Birthday Box
- Shared photos/stickers/drawings/voice gifts
- All gift builders
- Birthday-song recording
- Background Designer
- Owner PIN
- Drawing/mobile fixes

There is no Party Chat panel, Chat button, message composer, typing indicator,
join/leave message UI, or chat broadcasting in V19.


V20 — CREATOR STUDIO
--------------------
Major editor redesign focused on making the gift creator easier for first-time
users while keeping advanced controls.

New editor:
- Modern three-column Creator Studio on desktop
- Clear 3-step onboarding guide
- Searchable element library
- Element categories
- Large expanded emoji/decoration library
- Text presets: Heading, Subtitle, Short note
- New Shapes: Circle, Rounded square, Pill, Line, Frame
- Quick Text / Photo / Sticker / Background toolbar
- Contextual Edit inspector
- Opacity control
- Center horizontally / vertically
- Reset rotation
- Clickable Layers list for overlapping items
- Modern mobile bottom dock
- Full mobile Browse Elements sheet with search/categories
- Direct drag / corner resize / rotate / pinch remains
- Drawing mode remains
- Supabase online count remains
- Shared Birthday Box remains
- Public chat remains removed
